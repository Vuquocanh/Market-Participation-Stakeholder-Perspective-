# Market Participation Strategy — Wind Farm & Flexible Load

Stochastic offering strategy optimization for a price-taking wind farm in day-ahead and balancing markets, and optimal reserve bidding for a flexible load in the FCR-D UP ancillary service market.

---

## Requirements

- Python 3.9+
- [Gurobi](https://www.gurobi.com/) with a valid license
- Dependencies: `gurobipy`, `pandas`, `numpy`, `matplotlib`

Install dependencies:
```bash
pip install pandas numpy matplotlib
```

## Getting Started

**Step 1 — Convert input data** (run once):
```bash
python convert_xlsx_to_csv.py
```
Reads `Input_data.xlsx` and writes all scenario sheets as CSV files into the `data/` folder.

**Step 2 — Run all tasks:**
```bash
python main.py
```
Runs all 7 tasks in sequence and saves results to `results/Task_X_Y/` as CSV files.

**Step 3 — Plot figures:**

Open `plot_figures.ipynb` in Jupyter and run all cells. Figures are saved as PDF files into the corresponding `results/` subdirectories.

## Task Overview

### Step 1 — Day-Ahead and Balancing Markets

Wind farm: 500 MW installed capacity, price-taking, DK2 market.  
Scenarios: **1600 combined** = 20 wind × 20 price × 4 imbalance (all equally probable).

| Task | Description | Output |
|------|-------------|--------|
| 1.1 | Stochastic offering strategy — **one-price** balancing scheme | `q_DA.csv`, `profit_scenario.csv`, `expected_profit.csv` |
| 1.2 | Stochastic offering strategy — **two-price** balancing scheme | same structure as 1.1 |
| 1.3 | **8-fold cross-validation** (200 in-sample / 1400 out-of-sample) for both schemes | `cv_results.csv`, `cv_averages.csv` |
| 1.4 | **Risk-averse** strategy via CVaR (α = 0.90), β swept 0 → 1, both schemes | `efficient_frontier.csv` |

Balancing price model:
- System deficit (SI = 1): BP = 1.25 × DA price
- System surplus (SI = 0): BP = 0.85 × DA price

### Step 2 — FCR-D UP Ancillary Service Market

Flexible load: 0–600 kW consumption, DK2 market, single bidding hour (minute-level, 60 steps).  
Profiles: **300 generated** = 100 in-sample + 200 out-of-sample.

| Task | Description | Output |
|------|-------------|--------|
| 2.1 | Optimal FCR-D UP reserve bid satisfying **P90** requirement via **ALSO-X** and **CVaR** | `reserve_bids.csv`, `load_profiles.csv` |
| 2.2 | **Out-of-sample verification** of P90 requirement for both methods (no optimization) | `p90_verification.csv` |
| 2.3 | **P-requirement sensitivity** sweep (80%–100%) using ALSO-X; trade-off between reliability and reserve provision | `p_requirement_sweep.csv` |

## Notes

- The `data/` folder is generated locally by `convert_xlsx_to_csv.py` and is not tracked by Git.
- Task 2.1 load profiles are generated with a fixed seed (`seed=42`) for reproducibility. Re-running `main.py` will produce identical profiles.
- Gurobi solver output is suppressed by default (`OutputFlag = 0`) in all model files.
- Historical wind data is sourced from [FINGRID](https://data.fingrid.fi/) / [ELIA](https://www.elia.be/en/grid-data) / [Renewables.ninja](https://www.renewables.ninja/); day-ahead prices from [Nord Pool (DK2)](https://www.nordpoolgroup.com/).
